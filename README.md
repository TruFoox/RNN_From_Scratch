A simple, single-layer vanilla-style RNN written in C++, that can be trained to estimate the result of mathematical operations.
The user can input the maximum number allowed to be randomly chosen for the operation at each pass (though really big numbers slow it down as it requires a higher weight dimension), and the type of operation being performed
